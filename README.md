> 자경단원이 발견한 꿀팁·자료·트릭 모음입니다. 길고양이가 햇볕 잘 드는 평상을 알려주듯, 저희도 좋은 자리는 숨기지 않습니다.

자경단의 행동강(綱)냥(領) **3조 — 지식 공유**: *꿀잠 스팟은 숨기지 않습니다.*

## 한 항목 형식

각 마크다운 파일은 다음 골격을 따릅니다.

```markdown
# {짧고 구체적인 제목}

> 한 줄 요약 — "왜 이게 꿀잠인가"

## 상황
어떤 골목에서 마주치는 문제인지.

## 그루밍
실제 해결 단계. 코드 블록 환영.

## 출처/참고
스택오버플로우, 공식 문서, 본인 삽질 등.

---
**발견자**: @누구 · {YYYY-MM-DD}
```

너무 길게 쓰지 않으셔도 됩니다. 7시간 자려고 7시간 동안 자리 알아보는 고양이는 없으니까요.

## PR 환영

자경단원이 아니셔도 PR 보내주실 수 있습니다. 자세한 건 [`CONTRIBUTING.md`](./CONTRIBUTING.md)에 한 줄 가이드로 적어두었습니다.

다음의 경우는 거절될 수 있습니다.

- 광고·스폰서 콘텐츠
- 검증되지 않은 보안·법률·의료 조언
- 특정 유료 서비스만이 정답이라고 주장하는 글
- 어린이·노인 대상 위험 행위
